# Intake skills

Skills in this stage gather information, analyze requirements and build context before a
feature or fix is implemented. This directory is a **grouping folder, not a skill** — each
subdirectory is one skill.

| Skill | Description |
|-------|-------------|
| [azure-devops](azure-devops/SKILL.md) | Retrieve Azure DevOps work item details, relations, history, tags and state |

Install one directly:

```bash
npx skills add imyesobo/my-agent-skills --skill azure-devops
gh skill install imyesobo/my-agent-skills azure-devops
```
